# 180. Consecutive Numbers

Find every number that appears at least three times in a row, ordered by `id`, as `ConsecutiveNums`.

`lag` reads the two previous rows in `id` order. Comparing ids as well guards against gaps in the ids, which the problem's data does not have but real data might.
